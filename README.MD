## 📝 How to Use This Repo

1. **View the HTML page**: Open `index.html` in any web browser
2. **Clone locally**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/html-learning.git
   cd html-learning
   open index.html
   ```
3. **Check `.gitignore`**: See what files are excluded from Git tracking
